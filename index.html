1我们收集的信息

我们不收集您的任何个人信息。

  • 不收集姓名、手机号、邮箱等账号信息（本应用无账号体系）；
  • 不收集位置信息、通讯录、相册、麦克风、摄像头等系统敏感数据；
  • 不收集使用行为、崩溃日志等统计数据；
  • 学习进度、宝石、星星等数据仅保存在您的设备本地，不上传任何服务器。
✅ 本应用无广告、无内购、无社交功能，儿童可独立安全使用。

2权限说明

本应用申请的权限及其用途如下：

  • 通知（POST_NOTIFICATIONS）：用于每日练习提醒。需您在系统设置中授权；未授权时应用仅使用本地定时提醒，不会打扰您；
  • 震动（VIBRATE）：仅在答题时提供触觉反馈；
  • 网络（INTERNET）：仅用于华为设备上的推送服务通道连接，应用本身不发起任何网络请求；
  • 开机启动（RECEIVE_BOOT_COMPLETED）/ 精确闹钟（SCHEDULE_EXACT_ALARM）/ 唤醒锁（WAKE_LOCK）：用于重建每日定时提醒。

除上述权限外，应用不申请存储、位置、麦克风、摄像头等其他权限。

3华为推送服务说明

在华为手机上，本应用集成华为推送服务（HMS Push）以发送「每日练习提醒」：

  • 华为推送可能生成并传输推送令牌（Push Token）至华为服务器，用于识别接收设备；
  • 该过程由华为推送 SDK 完成，相关信息的处理遵循《华为隐私政策》；
  • 在非华为设备上，推送功能自动关闭，仅使用本地提醒；
  • 我们自身不收集、不存储、不使用推送令牌，也无法查看您的任何设备信息。
⚠️ 如需彻底关闭提醒：系统设置 → 通知 → 打字小公主 → 关闭通知。

4数据存储

  • 学习进度（已过关卡、宝石、星星、连胜天数）仅保存在本机；
  • 这些数据不会同步到任何服务器，我们也无法查看；
  • 您可以在「我的 → 设置」中随时清空学习数据，卸载应用同样会彻底删除。

5儿童保护

本应用面向 3~8 岁儿童设计，我们坚持：

无广告无内购无社交 无外部链接无个人信息收集

儿童可独立安全使用，家长无需担心隐私泄露或误付费。

针对不满十四周岁的儿童用户，我们另行制定了 《儿童个人信息安全规则》， 专门说明儿童个人信息的处理目的、方式与范围、存储与保护措施， 以及儿童与监护人行使访问、更正、删除、撤回同意等权利的方式。 该文件与本文不一致之处，以《儿童个人信息安全规则》为准。

举报渠道：如发现任何危害未成年人身心健康的内容或行为， 请通过应用内「设置 → 举报与反馈」或发送邮件至 houxuelongahut@163.com 进行举报。我们会在 3 个工作日内受理并回复， 并对举报人信息严格保密。

6第三方服务

本应用仅集成华为推送服务（HMS Push，仅华为设备生效），用于发送学习提醒，不存在其他第三方 SDK（无统计、无广告、无支付、无分享组件），不存在向其他第三方共享数据的情况。

7您的权利

  • 由于我们不收集个人信息，您无需注册即可完整使用全部功能；
  • 您可随时在应用内查看、修改昵称与头像；
  • 您可随时在「我的 → 设置 → 清空学习数据」中删除全部本地数据；
  • 卸载应用即彻底删除全部数据，等同于撤回全部同意。

8隐私政策的更新

如因功能调整导致隐私政策变化，我们会在应用新版本中同步更新本页面，并通过版本说明告知。重大变更将提前显著提示。

9附：儿童个人信息安全规则（全文）

适用对象：不满十四周岁的儿童用户及其监护人。以下为《儿童个人信息安全规则》完整内容， 单独页面地址：https://lynnhou.github.io/dazi-privacy/children.html

9.1 我们如何处理儿童个人信息：一句话结论

✅ 我们不收集儿童的任何个人信息。本应用无账号、无注册登录、无社交互动、无广告、无内购、无第三方统计， 儿童在使用过程中的全部学习数据（已过关卡、星星、宝石、连胜天数、昵称与头像选择） 仅保存在儿童所使用的这台设备的本地存储空间中，不会上传至任何服务器， 开发者与任何第三方均无法查看、获取或使用。

9.2 处理目的、方式与范围

  • 目的：在本机设备上保存并展示学习进度，实现闯关解锁、宝石合成、装扮购买等应用内学习激励功能；
  • 方式：纯本地读写（Android 应用私有存储目录），不联网、不上传、不同步、不共享；
  • 范围：已完成关卡编号与得分、星星与宝石数量、连续学习天数、自建昵称与头像装扮选择（默认随机昵称，不要求真实姓名）、应用设置项，均不构成个人信息。
⚠️ 我们不收集儿童的真实姓名、出生日期、性别、住址、学校、手机号、邮箱、账号口令， 不收集人脸、指纹等生物识别信息，不收集地理位置、通讯录、短信、通话记录、相册、 麦克风、摄像头等敏感个人信息，不收集设备标识符用于追踪或画像。

9.3 儿童个人信息的存储与保护

  • 存储地点：仅保存在儿童所用设备的本地应用私有目录中，受 Android 系统沙箱保护；
  • 存储期限：自数据产生之日起至用户主动删除或卸载应用为止，卸载后即彻底清除，我们不做任何留存；
  • 安全措施：不联网传输、无服务端存储，从根源上避免泄露、篡改、丢失风险；
  • 如需清除：可在应用内「我的 → 设置 → 清空学习数据」随时删除，卸载应用同样会彻底删除。

9.4 访问、更正、删除与撤回同意

  • 查阅 / 复制：在应用内「我的」页面直接查看学习数据；
  • 更正 / 补充：在「我的 → 个人设置」中随时修改昵称与头像；
  • 删除：在「我的 → 设置 → 清空学习数据」中一键清除，或卸载应用；
  • 撤回同意：卸载应用即视为撤回全部同意。

9.5 不共享、不转让、不公开披露

不共享给第三方不转让不公开披露 不发生跨境提供

唯一的第三方组件为华为推送服务（HMS Push，仅华为设备生效），用途仅为下发「每日练习提醒」本地通知， 由华为推送 SDK 完成，可能产生用于识别接收设备的推送令牌并由华为处理， 遵循《华为隐私政策》。 我们自身不收集、不存储、不使用该令牌，也不会以该令牌关联任何儿童身份。

9.6 面向儿童的设计保障

无账号注册无广告无内购付费 无社交聊天无用户生成内容 无外部网页跳转无个性化推荐

  • 儿童可独立使用，无需提供任何身份信息即可开始学习；
  • 应用内不含任何诱导消费、诱导分享、诱导填写资料的设计；
  • 所有音效、动画、奖励均为正向学习激励，不存在沉迷诱导机制。

  • 如发现儿童误填真实身份信息，可随时修改或彻底删除；
